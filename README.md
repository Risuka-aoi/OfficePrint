# OfficePrint

OfficePrint は、**Excel / Word / PowerPoint ファイルをフォルダ単位で抽出して一括印刷**するための Excel VBA ツールです。実装本体は `PrintTool.bas` です。

## 前提条件

- Windows + Excel（VBA 実行可能）
- Word / PowerPoint ファイルを印刷する場合は、それぞれのアプリがインストールされていること
- 印刷先は Windows の既定プリンタ

## 対応ファイル形式

- Excel: `.xlsx`, `.xlsm`, `.xls`
- Word: `.docx`, `.docm`, `.doc`
- PowerPoint: `.pptx`, `.pptm`, `.ppt`

※ 一時ファイル（`~$` で始まるファイル）は自動除外されます。

## セットアップ

1. マクロ有効ブック（`.xlsm`）を作成する。
2. 以下 3 シートを作成する（名前は完全一致）。
   - `メイン`
   - `ファイル一覧`
   - `ログ`
3. VBE で `PrintTool.bas` をインポートする。
4. `メイン` シートに以下の入力欄を用意する。
   - `B2`: 対象フォルダ
   - `B3`: 全体部数（1〜2,147,483,647 の整数）
5. ボタンを配置し、以下のマクロを割り当てる。
   - 一覧抽出: `一覧抽出ボタン_Click`
   - 印刷: `印刷ボタン_Click`
   - ログクリア: `ログクリアボタン_Click`

## 使い方

1. `メイン!B2` に印刷対象フォルダを入力。
2. `一覧抽出` ボタンを押下。
   - サブフォルダを含めるか確認されます。
   - `ファイル一覧` シートに対象ファイルが出力されます。
3. `メイン!B3` に全体部数を入力。
4. `ファイル一覧` シートの `印刷対象` 列を必要に応じて編集。
   - `TRUE` または空欄: 印刷対象
   - `FALSE`: スキップ
5. `印刷` ボタンを押下。
6. 結果は `ファイル一覧` の「印刷結果 / メッセージ」と `ログ` シートに記録されます。

## シート仕様

### メイン
- `B2`: 対象フォルダ
- `B3`: 全体部数

### ファイル一覧
- A列: 印刷対象（`TRUE` / `FALSE` / 空欄）
- B列: ファイル種別
- C列: ファイル名
- D列: フルパス
- E列: 印刷結果
- F列: メッセージ

### ログ
- 実行日時
- 処理種別
- ファイル名
- 結果
- メッセージ
- フルパス

## 注意事項

- 印刷処理で開いたファイルは、保存せず閉じます。
- マクロセキュリティ対策として、Excel ファイル印刷時は対象ブックを「マクロ無効」で開きます。
- 大量印刷時は処理に時間がかかるため、事前に `ファイル一覧` で対象確認を推奨します。
