# OfficePrint

OfficePrint は、**Excel から Word / Excel / PowerPoint ファイルを一括印刷するための VBA モジュール**です。  
実装本体は `PrintTool.bas` にまとまっています。

## このコードが「シンプルで確実に動く」理由（確認結果）

`PrintTool.bas` をレビューした結果、次の点で実運用しやすい構造になっています。

- **入口が明確**: 実行マクロは `一覧抽出ボタン_Click` / `印刷ボタン_Click` / `ログクリアボタン_Click` の 3 つに限定。  
- **入力検証がある**: 対象フォルダの存在確認、部数の整数チェック（1 以上）を実施。  
- **印刷対象の判定が明確**: `印刷対象` 列は `TRUE / FALSE / 空欄` のみを想定し、不正値はスキップ。  
- **後片付けがある**: Word / PowerPoint / 開いたブックを確実に閉じる `Cleanup` パスを実装。  
- **ログと結果が残る**: 一覧シートに結果、ログシートに時刻付き履歴を記録。  

> 上記のため、過度に複雑な依存や隠れた状態管理が少なく、保守しやすい構成です。

---

## 前提条件

- Windows + Microsoft Office（Excel / Word / PowerPoint）がインストール済み
- Excel でマクロを有効化できること
- 印刷先は **Windows の既定プリンタ**

---

## セットアップ

1. マクロ有効ブック（`.xlsm`）を作成
2. 次の 3 シートを作成
   - `メイン`
   - `ファイル一覧`
   - `ログ`
3. VBE（Visual Basic Editor）で `PrintTool.bas` をインポート
4. `メイン` シートに入力欄を用意
   - `B2`: 対象フォルダ
   - `B3`: 全体部数（1 以上の整数）
5. ボタンに以下マクロを割り当て
   - 一覧抽出: `一覧抽出ボタン_Click`
   - 印刷: `印刷ボタン_Click`
   - ログクリア: `ログクリアボタン_Click`

---

## 使い方

1. `メイン!B2` に対象フォルダを入力
2. `メイン!B3` に部数を入力
3. `一覧抽出` を実行
   - 必要に応じてサブフォルダを含める
4. `ファイル一覧` シートで `印刷対象` を調整
   - 空欄または `TRUE`: 印刷対象
   - `FALSE`: スキップ
5. `印刷` を実行
6. 実行後、`印刷結果/メッセージ` および `ログ` を確認

---

## 対応ファイル

- Excel: `xlsx`, `xlsm`, `xls`
- Word: `docx`, `docm`, `doc`
- PowerPoint: `pptx`, `pptm`, `ppt`

※ 先頭が `~$` の一時ファイルは除外します。

---

## 出力項目

### ファイル一覧シート（1 行目ヘッダ）
- 印刷対象
- ファイル種別
- ファイル名
- フルパス
- 印刷結果
- メッセージ

### ログシート（1 行目ヘッダ）
- 実行日時
- 処理種別
- ファイル名
- 結果
- メッセージ
- フルパス

---

## 注意事項

- 読み取り専用で開いて印刷し、保存せず閉じます。
- 印刷の成否は、Office 側エラーやプリンタ状態の影響を受けます。
- シート名（`メイン` `ファイル一覧` `ログ`）はコード定数と一致が必要です。
