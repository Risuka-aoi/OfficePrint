# OfficePrint

Excel VBA の一括印刷ツールです。実装本体は `PrintTool.bas` にあります。

## 使い方
1. マクロ有効ブック（`.xlsm`）を作成し、シート `メイン` `ファイル一覧` `ログ` を作成。
2. `PrintTool.bas` をVBEからインポート。
3. `メイン` シートの `B2` に対象フォルダ、`B3` に全体部数を入力。
4. ボタンに以下マクロを割り当て。
   - 一覧抽出: `一覧抽出ボタン_Click`
   - 印刷: `印刷ボタン_Click`
   - ログクリア: `ログクリアボタン_Click`

## メモ
- 印刷先は Windows 既定プリンタ。
- 印刷時に開いたファイルは保存せずに閉じます。
- `印刷対象` 列は `TRUE/FALSE/空欄` のみを使用します（空欄は印刷対象）。
